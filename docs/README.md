# 文档地图

本目录保存产品定位、研究流程、系统架构、数据规范、治理规则、安装记录和当前路线图。
第一次阅读建议先看“先读”部分，再按任务进入其他分类。

## 先读

| 文档 | 适合读者 | 作用 |
|---|---|---|
| [产品说明与使用指南](11-产品说明与使用指南.md) | 所有用户 | 了解产品解决什么问题、怎么使用、状态机和当前实际场景 |
| [系统架构](12-系统架构.md) | 用户、开发者、自动化代理 | 了解模块、数据流、策略流、安全边界和技术选择 |
| [当前状态与路线图](13-当前状态与路线图.md) | 用户、项目维护者 | 查看已完成、阻塞、真实数据状态和下一步优先级 |
| [个人量化策略研究工作法](07-个人量化策略研究工作法.md) | 策略研究者 | 理解策略优先、冻结基准、单假设和轻量实施原则 |
| [产品需求规格 v1](15-产品需求规格-v1.md) | 用户、产品和开发者 | 冻结 Agent-first 产品需求、页面、状态机、验收和 kill assumptions |
| [产品化目标架构 v1](16-产品化目标架构-v1.md) | 开发者、Agent 维护者 | 定义控制平面、Provider/Target 二维模型、API、Worker 和审计 |
| [架构重构实施计划](17-架构重构实施计划.md) | 项目维护者 | 说明 Phase 0 纵切、后续阶段、验证和回滚边界 |
| [Agent 与 Skill 执行架构](18-Agent与Skill执行架构.md) | Agent、开发者、审阅者 | 定义强制文档路由、Skill、工具白名单、状态机、Worker 和共享协议 |
