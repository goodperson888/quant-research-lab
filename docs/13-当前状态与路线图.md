## 路线图

### P0：形成第一个可运行基准

1. 收录用户第一份自然语言/Pine/公开策略；
2. 形式化所有规则和模糊点；
3. 冻结原样 15m 基准；
4. 安全解决或缓存可信的 Binance/OKX 市场 metadata；
5. 使用 taker 0.05%/side、2 bps/side 滑点和真实 funding 运行基准；
6. 保存实验 manifest、交易明细、数据版本、成本和失败原因。

P0 不允许参数优化，目标只是证明基准流程正确、无未来数据和可重复。

### P1：样本外和压力测试

1. 定义训练、验证和锁定测试时间段；
2. 每次只验证一个改进假设；
3. 对复杂组合执行消融；
4. 运行 Walk-forward；
5. 测试 5 bps 滑点、费用/滑点翻倍、延迟、漏单和参数扰动；
6. 记录测试集污染和失败实验。

### P2：组件沉淀与 dry-run

1. 只保留有稳定样本外增量的因子/过滤器/仓位/风控组件；
2. 记录按市场独立的验证状态；
3. 建立策略漂移、回撤和信号监控；
4. 候选通过门禁后进入 dry-run；
5. 对比模拟盘信号、滑点、成交和回测。

### P3：扩展历史和第二市场

1. 扩展 ETH 永续至更长历史和更多市场状态；
2. 网络恢复后补 OKX 同窗口和更长数据；
3. 比较 Binance/OKX 的信号、成本和执行差异；
4. 评估第二资产或第二市场，但不同时建设全部市场；
5. 仅在单机架构出现可测量瓶颈后评估更重基础设施。
