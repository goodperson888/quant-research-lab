# 安全与实盘门禁

## 密钥

- 仓库中不得出现密钥、密码、Cookie 或账户文件。
- 密钥只通过环境变量或外部密钥管理器注入。
- API 必须关闭提现权限并配置 IP 白名单。
- 回测和公共行情下载不需要交易密钥。

## 实盘门禁

进入实盘前必须全部满足：

1. 代码、数据和配置被冻结并版本化；
2. 最终样本外与压力测试通过；
3. 模拟盘积累了足够交易样本；
4. 实际滑点与回测差异可解释；
5. 每日损失、最大回撤、仓位和杠杆限制已设置；
6. 断线、行情异常和下单异常能够停止交易；
7. 人工明确批准交易所、账户、资金上限和期限。

自动研究任务永远无权绕过这些门禁。
