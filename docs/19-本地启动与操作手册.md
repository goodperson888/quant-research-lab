# 本地启动与操作手册

## 1. 安全边界

本手册只用于本地历史研究、报告和 dry-run 准备。API 和 Web 都没有 live trade、
密钥、任意 Shell 或自动 production 晋升接口。不要在任何项目文件中填写交易密钥。

## 2. 首次安装与检查

```bash
cd /Users/laochen/Documents/lianghua/quant-research-lab
./scripts/bootstrap.sh
./scripts/doctor.sh
```

`bootstrap.sh` 把 uv、Python 3.12、`.venv` 和缓存留在项目目录。`doctor.sh` 应显示
Python 3.12、注册表和产品 SQLite 已就绪，且 `live_trading_enabled=false`。

## 3. 启动 API 和 Web

终端 A：

```bash
cd /Users/laochen/Documents/lianghua/quant-research-lab
./scripts/dev-api.sh
```

API 默认只监听 `http://127.0.0.1:8000`，OpenAPI 在
`http://127.0.0.1:8000/docs`。

终端 B：

```bash
cd /Users/laochen/Documents/lianghua/quant-research-lab
./scripts/dev-web.sh
```

打开 `http://127.0.0.1:3000/studio`。Studio 展示 Agent 状态、Pipeline Profile、门槛、
StrategyOutcome、组件分流、regime 证据和 Pine 验证阶段。Embedded Provider 未配置时
不会伪造 AI 回复。

## 4. Worker 是 one-shot

```bash
./scripts/dev-worker.sh
```

无 `--job-id` 时，命令只打印 `execution_mode=one_shot`、已注册 Handler 和安全状态，
然后立即退出。它不是正在运行的队列服务。

只有 API/CLI 先创建白名单 Job 后，才使用：

```bash
./scripts/dev-worker.sh --job-id job_xxx
```

Worker 一次只执行一个 Job 并退出。它不接受任意命令。Full stress 还会复查
同一 strategy version 的 passed viability gate。

## 5. 首个策略输入流程

1. 在 Studio 选择自然语言、Pine 或文件来源，粘贴原始内容。
2. 保存 Draft；原文不会被 AI 覆盖。
3. 确认市场 Profile、时间、成本、入出场和模糊点。
4. 审批按钮展示精确 Draft/Plan/Version `subject_id`，确认后冻结 baseline v0。
5. 选择 `smoke`、`fast_screen` 或 `full_validation`。
6. 按 correctness → fast screen → viability 执行；失败即停止昂贵流程。
7. “少亏”只记为 diagnostic improvement；局部组件单独记录 lineage 和证据。
8. 只有 viability 通过后才进入 regime/Pine、锁定测试和 full stress。

## 6. 停止

- API/Web 在各自终端按 `Ctrl-C`。
- Worker 正常会在单个 Job 完成或失败后自行退出。
- 不要用 `kill -9` 作为常规停止方式；先保留 Job 日志和部分 Artifact。

## 7. 排错

- API 不通：运行 `./scripts/doctor.sh`，再检查 `curl http://127.0.0.1:8000/health`。
- Web 显示空态：确认 API 已启动，且 `NEXT_PUBLIC_QUANT_LAB_API_URL` 没有指向其他主机。
- Job 一直 queued：确认是否已显式执行 `dev-worker.sh --job-id ...`。
- Full stress 被拒绝：查看同一 subject 的 viability gate ID，不要伪造通过状态。
- Pine 对账未开始：这可能是正常 fail-fast；完整诊断在 viability 后。
- Freqtrade 市场 metadata 直连超时：保留失败日志；如用户明确提供本机代理，可用临时
  overlay 的 `aiohttp_proxy` 做公开 metadata smoke，不把代理写入仓库或环境文件。
- funding/mark/index/OI 缺口：查看年度 manifest，不得静默填 0 或用未来值补齐。

只读治理检查：

```bash
PYTHONPATH=src .venv/bin/python -m quant_lab.cli storage-report
PYTHONPATH=src .venv/bin/python -m quant_lab.cli list-backtest-engines
./scripts/freqtrade.sh list-data \
  --config configs/freqtrade.binance.eth.futures.json \
  --datadir runtime/freqtrade/user_data/data/binance
```

`storage-report` 不删除文件。引擎列表只声明能力，不运行回测；Freqtrade `list-data` 只读
检查本地数据容器。

## 8. 数据和状态备份

大数据不进 Git。关闭 API/Worker 或确认没有写入后，备份：

- `data/raw/`、`data/processed/` 和 `data/manifests/`；
- `runtime/app/quant_lab.sqlite3`（以及存在时的 WAL/SHM）；
- `factor_library/registry.sqlite3`；
- `experiments/runs/`、`reports/`和策略源码。

建议至少“本机 + 外接盘 + 异地”。恢复后先运行 doctor、pytest 和数据 manifest 校验。

```bash

./scripts/freqtrade.sh trade
```

第二条必须被安全门禁拒绝并返回退出码 3。
