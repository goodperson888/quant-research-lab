# 自动化运行规范

## 每日任务

每日任务以监控和回归验证为主：

1. 更新数据；
2. 数据质量检查；
3. 单元测试；
4. 最新滚动样本外测试；
5. 因子健康度和策略漂移检查；
6. 生成日报；
7. 触发风险告警，但不自动开启实盘。

## 每周任务

每周任务承担较重研究：

1. 候选因子计算；
2. 有限预算参数搜索；
3. Walk-forward；
4. 成本和压力测试；
5. 因子相关性、去重和组合；
6. 状态更新建议；
7. 生成周报。

## 自动任务禁止事项

- 每天盲目重新优化生产参数；
- 使用锁定测试集指导修改；
- 自动把策略晋升到生产；
- 自动增加杠杆、资金或实盘权限；
- 隐藏失败结果；
- 在没有版本和运行清单的情况下覆盖结果。
