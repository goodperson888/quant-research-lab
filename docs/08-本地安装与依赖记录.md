# 本地安装与依赖记录

记录日期：2026-07-21
主机：Apple Silicon arm64，macOS 15.5
磁盘：项目所在卷约 150 GiB 可用（安装前）

## 隔离边界

- 系统 Python 3.9.6 不安装任何项目包。
- 项目固定使用 Python 3.12.13，由 uv 安装到 `.tools/python/`。
- uv 固定为 0.11.29，安装到 `.tools/bin/`。
- 虚拟环境固定为 `.venv/`。
- uv、XDG 和下载缓存固定在 `.cache/`。
- 依赖下载使用清华 PyPI 镜像；版本与文件哈希由 `uv.lock` 固定。
- 不在仓库保存交易所密钥、Cookie、密码或提现凭据。

## 第一阶段依赖

第一阶段包含 pytest、pytest-cov、NumPy、pandas、PyArrow、DuckDB、PyYAML、
CCXT、QuantStats 和 Freqtrade 2026.6。产品化阶段 0 增加 FastAPI 0.139.2、
Pydantic 2.13.4 和 Uvicorn 0.51.0。传递依赖的精确版本以 `uv.lock` 为准。

Freqtrade 只安装基础包，不安装 `hyperopt`、FreqAI 或强化学习 extras。因此不会
额外引入 Optuna、LightGBM、XGBoost、PyTorch 等大型依赖。需要参数搜索时，应先
定义策略、数据切分和计算预算，再作为独立阶段评估。

## Freqtrade 选择依据

- 固定版本：2026.6（PyPI 正式发布版）。
- Python 要求：`>=3.11`；本项目使用 3.12。
- 许可证：GPLv3。
- 第一阶段用途：历史数据工具、回测、结果分析和后续 dry-run。
- `trade` 命令被 `scripts/freqtrade.sh` 默认拒绝，避免误启动交易循环。

## 已确认的第一阶段市场

- 资产：ETH；
- 工具：USDT 本位永续；
- 请求主源：OKX；跨所对照：Binance；
- 周期：5m、15m、1h、4h；第一候选默认 15m；
- 窗口：2026-04-21T00:00:00Z 至 2026-07-20T00:00:00Z，90 个完整 UTC 日；
- 成本：taker 0.05%/side + 2 bps/side 基准滑点，另有 5 bps 滑点和费用/滑点翻倍压力；
- 风险：leverage=1，live trading 关闭。
