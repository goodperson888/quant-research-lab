# 压力测试清单

## 两级压力测试

- `cheap_cost_sensitivity`：fast screen 通过后的廉价 kill test，包括提高手续费、
  滑点或执行延迟的少量情景；它不代表完整 robustness。
- `full`：只允许对同一 strategy version 已通过 viability 的对象运行，
  并要求精确 `subject_id` 审批。后端和 Worker 都必须重新检查门槛。

候选策略至少执行以下测试：

- 手续费提高；
- 滑点提高；
- 入场和出场延迟；
- 参数轻微扰动；
- 不同资产、周期和交易所；
- 牛市、熊市、震荡、高波动和低流动性阶段；
- 删除最佳若干笔交易；
- 随机漏单；
- Monte Carlo 交易重排或收益重采样；
- 流动性和容量限制；
- 断线、缺K线、重复数据和异常价格；
- 仓位、精度、最小金额和资金不足。

输出必须包含基准结果、压力结果、差异和失败原因。

压力与参数 Job 还必须受 ResearchSession 总预算和 Worker RSS/时间预算约束。超限属于
可审计的 blocked/failed 证据，不能通过拆分对话或重复排队绕过。
