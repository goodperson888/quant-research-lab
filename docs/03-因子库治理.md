# 因子库治理

## 因子状态

- `candidate`：候选研究；
- `validated`：通过样本外和压力测试；
- `production`：经人工批准进入生产策略；
- `degraded`：近期衰减，等待复核；
- `retired`：停止使用；
- `rejected`：验证失败但保留记录。

## 每个因子必须记录

- 唯一ID、名称、分类和版本；
- 公式与代码路径；
- 数据需求、回看长度和可用时间点；
- 方向、标准化方法和缺失值处理；
- 适用资产、周期和市场状态；
- 样本内、样本外、Walk-forward 和成本压力结果；
- 换手率、衰减速度和容量；
- 与已有因子的相关性；
- 创建来源、修改原因和状态历史。

## 晋升条件

因子不得仅凭历史收益晋升。至少需要：

- 无未来数据和时间泄漏；
- 多窗口样本外证据；
- 扣除真实成本后仍有增量；
- 参数扰动后稳定；
- 不依赖极少数异常交易；
- 与现有因子相比具有独立信息；
- 有可解释的市场逻辑。

`production` 状态必须人工批准，自动任务无权执行。
