# 市场适配与因子适用性

## 一、三层模型

因子和策略组件分为三层：

1. **通用因子思想**：例如动量、均值回归、波动、流动性或期限结构；
2. **市场适配实现**：针对具体资产类别、工具、场所、周期和数据语义的公式与执行；
3. **市场独有因子**：只存在于某类市场的数据，如永续资金费率、期货展期收益或期权
   隐含波动率偏斜。

推荐架构是“通用核心 + market adapter + market-native factors + 独立验证状态”。
代码可以复用通用思想，但数据定义、成本和结论不能偷懒复用。

## 二、验证结论不得跨市场传播

同名或同公式因子不能共享 `validated` 或 `production` 结论。必须按以下维度独立验证：

- 资产类别；
- 工具类型；
- 交易所、经纪商或数据源；
- 时间周期和交易时段；
- 手续费、点差、滑点、融资/资金费率和执行限制。

例如，加密现货 1 小时动量在某交易所验证通过，不代表同一公式在股票日线、期货连续
合约、外汇 tick volume 或加密永续上验证通过。每个 market profile 都有独立实验、
证据和状态。

## 三、市场范围与必需适配

### 股票

股票研究必须处理前复权/后复权或不复权口径、分红拆股、财报与公告的真实可得时间、
行业与市值、停牌、退市、涨跌停、做空与借券限制。股票池必须包含历史退市标的或说明
数据限制，禁止只保留当前上市股票造成幸存者偏差。

### 交易所期货

必须区分具体可交易合约与研究用连续合约。连续序列需要记录主力选择、换月规则、拼接
和复权方法，不能直接当成真实可交易合约。还需处理到期交割、合约乘数、保证金、涨跌
停、夜盘、交易日历，以及期限结构、基差、展期收益和持仓量。

### 外汇现货、远期与 CFD

外汇现货、远期和 CFD 是不同工具，必须明确区分。外汇没有统一中心化现货成交量，
经纪商 tick volume 只是特定数据源的活动代理，不能表述为全球真实成交量。研究需记录
经纪商报价、点差、隔夜利息/掉期、远期点、利差、交易时段、周末跳空、央行与宏观
事件，以及 CFD 的对手方和合约条款。

### 加密现货

加密现货需要考虑交易所分散、刷量和虚假流动性、稳定币流动性、链上数据的确认时间、
交易所流入流出、跨所价差、24/7 交易以及交易所停机和下架。

### 加密永续与交割合约

必须处理资金费率、基差、标记价格、指数价格、持仓量、强平数据、杠杆阶梯、维持保证
金、交易所故障和结算时点。永续合约不能只用最新成交价和手续费模拟执行。

### 期权预留

期权后续可支持隐含波动率、skew、term structure、Greeks、成交/持仓分布和 dealer
gamma 等。第一阶段只保留 profile 和接口位置，不实现完整波动率曲面或定价系统。

## 四、市场兼容状态

- `compatible`：数据和公式可在该 profile 计算，但尚无有效性结论；
- `candidate`：已形成待验证假设；
- `validated`：在该 profile 通过样本外、成本和压力测试；
- `production`：该 profile 下经人工批准进入生产策略；
- `not_applicable`：数据语义或工具机制不适用；
- `rejected`：在该 profile 验证失败并保留证据；
- `degraded`：原已验证结论在该 profile 出现衰减；
- `retired`：停止在该 profile 使用。

`production` 仍然要求人工批准。一个 profile 的状态变化不能自动改写另一个 profile。

## 五、market profile 是下载与研究门禁

market profile 至少定义：资产类别、工具类型、交易场所/经纪商、时区与交易时段、
品种、周期、必需数据集、成本模型、复权/换月/公司行为规则和市场特有风险。

profile 的 `enabled` 默认为 `false`。用户确认并填写一个 profile 前，不得下载或混合
行情，不得把不同场所、工具或数据语义拼成一个未标注的数据集。

## 六、个人阶段实施边界

架构可以支持股票、期货、外汇、加密和未来期权，但个人阶段只实现一个用户确认的主
市场。其他 profile 仅作模板和兼容性占位，按真实研究需求逐个增加适配、测试和数据，
不同时建设全部市场，更不因为“未来可能使用”而引入重型基础设施。
